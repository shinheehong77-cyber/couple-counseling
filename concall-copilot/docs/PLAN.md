# 콘콜 코파일럿 — 기획서 v0.1

> 2026-11-04 · 국내외 콘콜(실적 콜, IR 미팅, 전문가 콜)을 녹음하고, 통화 중 옆 화면에 "지금 고려·판단해야 할 것"을 실시간으로 띄워주는 개인용 시스템

## 1. 왜 만드나 — 기존 서비스 조사 결과

| 분류 | 대표 서비스 | 되는 것 | 안 되는 것 (우리 요구 대비) |
|---|---|---|---|
| 회의 기록 (통화 후 정리) | Otter, Fireflies, Granola, Fathom, 클로바노트, 다글로 | 녹음, 전사, 요약, 화자 구분, 한국어 지원(클로바노트·다글로) | 통화 **중** 판단 보조 없음. 대부분 통화 후 요약 |
| 실시간 "할 말" 오버레이 | Cluely, Convo, Final Round AI 등 | 통화 중 실시간 답변·추천 문구 | 면접·영업용. 투자 판단(숫자 비교, 이전 발언과의 모순)이나 **내 자료** 연결 없음. Cluely는 2025년 개인정보 유출 보도 |
| 투자 리서치 플랫폼 | AlphaSense (Live Transcripts, Tegus 전문가 콜) | 공개 실적 콜 실시간 자막, 전문가 콜 녹취록·AI 요약 | **상장사 공개 콜** 위주. 내가 직접 하는 비공개 IR·전문가 콜에 실시간 판단 카드를 띄우는 기능은 없음. 고가 |

결론: "통화 녹음 + 실시간 자막"과 "통화 후 요약"은 이미 흔하다. 하지만 아래 네 가지를 **한 화면에서, 통화 중에** 해주는 도구는 찾지 못했다.
1. 상대 발언의 **기술 해석** (무슨 뜻이고 투자 관점에서 왜 중요한가)
2. **내 자료**(지난 콜 메모, 리서치 노트, 가설)와 지금 발언의 연결·불일치
3. **웹 사실 확인** (출처 포함)
4. 그 결과로 "지금 물어볼 질문"과 "판단 포인트"

→ 직접 만든다. 단, 녹음·전사 엔진은 이미 좋은 API를 쓰고(바퀴를 다시 만들지 않음), 판단 보조 부분에 집중한다.

## 2. 사용 시나리오

1. **콜 전 (2분)**: 콜 제목·상대·목적·"내 가설/확인할 것"을 적는다 → "사전 브리핑" 버튼: 최근 뉴스 + 내 자료 요약 + 질문 리스트
2. **콜 중**: Zoom/Teams 옆에 창을 띄워둔다
   - 왼쪽: 화자별 실시간 자막 (나 / 상대 / 상대 2 …)
   - 오른쪽: 카드가 쌓인다 — 판단 · 질문 · 기술 · 숫자 · 내 자료 · 웹 확인
   - 하단: 짧게 물어보기 ("방금 말한 수율이 경쟁사보다 높은 거 맞아?")
3. **콜 후**: "종료 & 메모" → 콜 메모 자동 작성(결론, 숫자 표, 이전 대비 변화, 가설 점검, 후속 질문) → **자동으로 내 자료에 저장** → 다음 콜 때 "지난번엔 40대라고 했는데 오늘은 30대 초중반" 같은 비교가 가능해진다

## 3. 시스템 구성

```
[브라우저 — 통화 옆 창]
  마이크(나) ─┬─▶ 말소리 구간 감지 → 16kHz WAV ─▶ [로컬 Whisper (whisper.cpp)] ─▶ 확정 발화 ─┐
  회의 탭/시스템 오디오(상대) ─┘   (또는 선택: Soniox 클라우드, 단어 단위 실시간)                 │
  두 소리를 섞어 녹음 ─▶ 5초마다 서버에 저장                    │
                                                              ▼
[로컬 서버 (Node)]  발화 저장 → 분석 스케줄러 (새 발화 120자 이상 or 12초)
    ├─ 내 자료 검색 (BM25 + 한글 2-gram, 임베딩 불필요)
    ├─ Claude: 실시간 카드 (구조화 출력, 빠른 응답 설정)
    │     └─ 사실 확인이 필요한 카드 → Claude + 웹 검색 (동시 1건, 20초 간격 제한)
    ├─ 묻기 / 사전 브리핑: Claude + 웹 검색 + 내 자료
    └─ 종료: 콜 메모 작성 → 내 자료로 색인
  ─▶ SSE 로 카드를 브라우저에 푸시
[data/ 폴더] calls/<id>/{meta, segments, cards, audio.webm, summary.md}, kb/
```

설계 결정
- **전사는 로컬이 기본**: 콘콜 녹음에는 비공개 정보(MNPI 가능성, NDA)가 섞이므로 오디오는 내 컴퓨터 밖으로 보내지 않는다. whisper.cpp + large-v3-turbo(Apple Silicon GPU 가속)로 무료·오프라인. 대가: 문장 단위로 1~3초 늦게 뜨고, 화자 분리는 소리 경로(마이크/회의 소리)로만. 외부로 나가는 것은 Claude 분석용 텍스트뿐.
- **화자 구분을 소리 경로로 해결**: 마이크 = 나, 회의 소리 = 상대. 화자분리 모델의 오류를 크게 줄이고, 상대 쪽만 다시 화자분리(상대 2, 3).
- **브라우저 → 음성인식 직결**: 서버를 거치지 않아 지연 최소. 장기 키는 서버에만 두고 1회용 임시 키만 브라우저에 준다.
- **분석 주기는 서버가 결정**: 클라이언트는 발화만 올린다. 분석이 도는 중 들어온 발화는 다음 라운드로.
- **프롬프트 캐시**: [콜 정보 + 이전 대화]는 라운드마다 뒤에만 늘어나므로 캐시가 맞는다 → 1시간 콜도 비용·지연이 크게 늘지 않음.
- **로컬 우선**: 녹음·전사·메모는 내 컴퓨터 `data/`에만. 서버는 기본적으로 127.0.0.1에서만 열림.
- **키 없이도 동작**: Claude 키가 없으면 규칙 기반(숫자 포착·용어 사전·내 자료 매칭·질문 힌트)으로, 음성인식 키가 없으면 브라우저 내장 인식/데모로.

## 4. 카드 정의

| 종류 | 언제 | 예 |
|---|---|---|
| 판단 | 모순, 회피성 답변, 내 메모와 다른 숫자, 과장 가능성 | "수주 목표 40대 → 30대 초중반으로 하향. '연간 큰 차이 없다'는 이연 물량 가정에 의존" |
| 질문 | 지금 던지면 좋은 후속 질문 (상대 언어로) | "이연된 물량 중 확정 PO 비중은요?" |
| 기술 | 기술·용어 해석 + 투자 함의 | "하이브리드 본딩: … 도입 시 TC 본더 수요 일부 대체" |
| 숫자 | 매출·마진·가이던스·CAPA·시점 정리 | "4Q 가이던스 1,100~1,200억, OPM 15% (3Q 17% 대비 하락)" |
| 내 자료 | 내 노트와 연결/충돌 | "2Q 메모: 하이브리드 본딩 평가 2027 하반기 → 오늘 2027 상반기로 당겨짐" |
| 웹 확인 | 공개 정보로 사실 확인 (출처) | "경쟁사 X도 2027 상반기 평가 장비 출하 발표 (기사 링크)" |

## 5. 단계별 로드맵

- **v0.1.1**: 로컬 전사(whisper.cpp) 기본화, 무음 환각 문구 필터
- **v0.2**: 로컬 전사 중간 자막(긴 발화를 몇 초마다 미리 보기), 로컬 화자 분리(상대가 여러 명일 때), 분석까지 완전 로컬 옵션(로컬 LLM — 품질 하락 감수), 데스크톱 앱 소리 캡처 개선(Electron/네이티브 루프백 → BlackHole 없이 Zoom 앱 소리), 단축키로 "방금 거 표시"(북마크), 카드 피드백(👍/👎)로 프롬프트 튜닝
- **v0.3**: 실시간 번역 자막(해외 콜, Soniox 번역 스트림), 종목별 워치리스트·이전 콜 자동 비교표, 엑셀 모델 가정값 연결
- **v0.4**: 팀 공유(메모 내보내기 → Notion/Drive), 컴플라이언스 옵션(MNPI 키워드 경고, 녹음 동의 체크)

## 6. 리스크 / 주의

- **녹음 동의**: 국내외 법규·상대 회사 정책에 따라 녹음 전 동의 필요. 화면에 안내 문구 표시.
- **MNPI**: 전문가 콜에서 미공개 중요정보가 나오면 판단 카드가 이를 증폭하지 않도록 v0.4에서 경고 기능.
- **지연**: 카드는 발화 후 수 초~십수 초. 기본 분석 모델은 정확도 우선(Claude Opus 5.5, 낮은 effort). 더 빠른 반응이 필요하면 `.env`에서 `LIVE_MODEL`을 Sonnet/Haiku로 바꿔 비교.
- **비용(대략)**: 로컬 전사는 무료(Soniox를 고르면 시간당 약 $0.12 × 2채널). Claude는 카드 라운드마다 과금되나 캐시로 반복 부분이 저렴.
